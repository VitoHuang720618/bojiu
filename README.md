
## 📊 服務管理 (PM2)
本專案後端服務名稱為 `bojiu-backend`。常用管理指令：
```bash
# 查看服務狀態
pm2 status

# 查看即時日誌 (排錯首選)
pm2 logs bojiu-backend

# 重啟服務
pm2 restart bojiu-backend

# 停止服務
pm2 stop bojiu-backend
```
